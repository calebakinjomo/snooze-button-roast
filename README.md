One line that roasts an alarm clock for ringing at 6 AM on a Saturday morning — entry for the [Snooze Button Roast bounty](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6) on make.fun.

## The entry

> It's 6 AM on a Saturday and my alarm clock is screaming like it pays the rent — the snooze button is the only one in this house who respects my boundaries.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22+) deterministically writes the single-line roast to `/output/entry.txt` (155 characters, within the 1–200 limit).
